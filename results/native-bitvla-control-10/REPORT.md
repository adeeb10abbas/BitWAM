# Native BitVLA control check

The released native ternary BitVLA checkpoint completed all 10 LIBERO-10 rollouts,
one trial per task. The official BitVLA evaluator and action/proprio heads were used
without controller changes.

This is an environment and policy sanity check, not a paper-level estimate. It proves
that native ternary pretraining preserves closed-loop behavior and establishes the
control against which BitWAM world-supervised post-training must be compared.
